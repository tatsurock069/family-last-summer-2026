# family-last-summer-2026

2026年8月15日〜16日の「関家 ラストサマー2026」専用PWAです。家族7人で、自宅（天下茶屋）から出発し、DAY1は生玉霊園での墓参りと生駒山上遊園地ナイター、DAY2は若狭和田ビーチを楽しむための実行アプリです。

## 既存アプリとの分離

このアプリは `family-trip-2026` を参考にした独立アプリです。既存アプリのリポジトリ、公開URL、旅行データには変更を加えていません。

- 新しい公開URL想定: `https://tatsurock069.github.io/family-last-summer-2026/`
- localStorage接頭辞: `seki-last-summer-2026:`
- Service Workerキャッシュ接頭辞: `seki-last-summer-2026-app-`
- manifest ID: `/family-last-summer-2026/`

## 主な機能

- 管理者が「完了して次へ」と遅延分数を更新できる、家族同期の「次の予定」
- 実際の進行に応じて終了済みの日程・チェック項目を非表示
- 生駒山上遊園地・若狭和田ビーチの観光地紹介
- 公式写真を使ったDAY1／DAY2カードと、4構図イラスト付き撮影指示書
- 「管理者（親）」だけが使える25,000円チャレンジ、実費・残額のリアルタイム表示
- 実費明細の追加、後編集、削除と管理者端末間の同期
- DAY1／DAY2向け買い出しチェック、担当分け、任意項目追加と家族同期
- DAY1／DAY2の持ち物チェックと家族同期
- ごはん、おかず、冷却、積み込みまでを確認する弁当準備工程
- 家族Vlog用20項目の撮影チェック、担当分け、撮り直し指示とフィルター
- 起動時に管理者（親）または使う子どもを選択（管理者以外には予算・実費を非表示）
- 管理者はミッション対象外とし、旅程・撮影・道具管理に集中できる4タブ構成
- 子ども5人別、5カテゴリ・各75項目のミッションと5個ごとのランク
- 「あんな」「はるな」は全ページがひらがなと幼児向けの短い言葉に切り替わる幼児モード
- 幼児モードの撮影項目は撮影操作ではなく、指さし・あいさつ・笑顔などの簡単な行動に変換
- 「撮影をお願い」したミッションを撮影タブに集め、「撮れた！」で撮影チェックとミッションを同時に完了
- 子どもの撮影依頼は管理者だけに配信し、管理者端末で撮影完了
- 通常ミッションは子どもの申告後に管理者が承認し、管理者は全員分の進捗を一覧確認
- 撮影リストは管理者・優典・綾菜だけに表示し、3人の端末間で進捗を同期
- Supabase Realtimeで予算、旅程進行、ミッション、撮影、買い出し、持ち物、弁当準備を役割別に同期
- 初回だけ家族コードを入力し、匿名端末認証＋RLSで家族メンバーだけが同期データへアクセス。管理者は追加の6桁PINが必要
- 圏外時の操作は端末内に保留し、次の操作・同期表示のタップ・アプリ再起動を起点に送信
- 同期状態、保留件数、最終同期を確認できる同期センター（定期通信なし）
- 管理者向け旅行記録JSON書き出し
- 撮影できなかった場合は「見届けたのでクリア」で、写真を強制しない運用に対応
- 端末内保存、PWA、オフライン表示

すべての記録はまず各端末に保存され、家族同期へ接続後は権限に応じて共有されます。位置情報と写真ファイルはクラウドへ保存しません。

## 家族同期

- DB定義: `supabase/schema.sql`
- 公開接続設定: `assets/js/sync-config.js`
- Supabaseのpublishable keyはブラウザ利用を前提とした公開キーです。secret keyやdatabase passwordはアプリへ保存しません。
- 本番の家族コードはリポジトリへ保存しません。

## ローカル確認

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。`file://` 直開きではService Workerは動作しません。

## 公開方法

1. `family-last-summer-2026` という独立GitHubリポジトリを作る
2. このディレクトリの内容を新リポジトリへコミットして `main` にpushする
3. GitHub Pagesを `main` / `/ (root)` で有効にする
4. 公開URLでPWA更新、オフライン表示、保存データを確認する

既存の `family-trip-2026` リポジトリへpushしないでください。
